Why EDGEFOLIO

Everything your factory needs.
Nothing it doesn't.

Built for the ground realities of Indian manufacturing — unreliable internet, power cuts, large workforces, and complex salary structures.

⚡
Works Without Internet
All data stored on your local PC using SQLite. Check-in, payroll, reports — everything works even during internet outages.
👁️
Face Recognition Attendance
Biometric-quality face recognition for automated check-in/out. No buddy punching, no manual entry errors.
💰
Smart Payroll Engine
Auto-compute salaries with PF, ESI, PT, TDS, OT, and custom deductions. Generate payslips in one click.
📊
Comprehensive Reports
Attendance registers, salary registers, muster rolls, and compliance reports ready for audit or submission.
☁️
Optional Cloud Backup
When internet is available, auto-sync encrypted backups to our VPS. Restore on any machine in minutes.
📱
Android Companion App
Staff can view payslips, apply for leave, and check attendance from their phones — syncs to the Edge Node via local WiFi.
📒
Cashbook & Expenses
Track daily cash in/out, petty cash expenses, and generate summaries — all in the same system.
🔒
Secure & Private
AES-256 encrypted backups. Your payroll data never leaves your premises without your explicit consent.
🇮🇳
India-First Design
Built for Indian compliance: PF, ESI, PT, Form-16, Muster Roll. INR currency, Indian date formats, Indian holidays.
Setup in minutes

How It Works

Get EDGEFOLIO running on your Windows PC in under 10 minutes.

1
Clone the repository
Pull the latest version from GitHub using git. No installer required — runs directly from source with Node.js.
2
Install dependencies
Run npm install in the EDGE/frontend and EDGE/backend folders. One-time setup.
3
Start EDGEFOLIO
Run npm run dev. Open your browser to localhost:5173 and log in with your admin credentials.
4
Add employees & start tracking
Import your staff from Excel or add them manually. Set shifts, salary structures, and you're ready to go.
5
(Optional) Connect to cloud
Enter your VPS token in Settings → Backup to enable encrypted cloud backup and remote monitoring from edgefolio.iotsoft.in.
