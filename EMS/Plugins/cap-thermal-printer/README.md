# @jenix/cap-thermal-printer

Reusable Android thermal printer bridge for Jenix applications.

Planned transport support:

- `ble`
- `usb`

Planned public API:

- `scan`
- `stopScan`
- `getDevices`
- `connect`
- `disconnect`
- `isConnected`
- `getStatus`
- `write`
- `printText`
- `feed`
- `printQRCode`
- `printBarcode`
- `printImage`
- `cut`
- `openCashDrawer`

Phase 0 includes package scaffolding, TypeScript definitions, web fallback, and
Android plugin registration only.
